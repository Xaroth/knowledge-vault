# Lessons

Self-contained teaching units for the [lead engineer](../index.md) track. Each
lesson is a single HTML file, completable quickly, that delivers one tangible win
tied to the [mission](../mission.md). Lessons share a common
[stylesheet](../assets/lesson.css) so the track reads as one course.

Lessons are numbered in teaching order. Open one directly in a browser, e.g.
`xdg-open 0001-what-is-a-lead-engineer.html`.
