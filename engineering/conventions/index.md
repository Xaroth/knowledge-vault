# Engineering conventions

Working conventions for code and repositories — the standards we check our own
engineering work against. Distinct from the vault's own
[authoring conventions](../../conventions/index.md), which govern how knowledge here
is written.

* [Semantic commit messages](./semantic-commit-messages.md) - the Conventional Commits grammar every commit subject follows: a typed, optionally scoped, present-tense subject with breaking-change markers and a PR suffix.
