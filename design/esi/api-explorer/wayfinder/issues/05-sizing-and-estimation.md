# Sizing & estimation approach

- **Type:** grilling
- **Status:** open
- **Blocked by:** 01, 02

## Question

How does the plan express effort/sizing (t-shirt sizes, story points, ideal-days), and what
estimation approach and confidence do we attach to each buildable unit?

The POC already validates much of the renderer, and docs `03`/`12` give a concrete module
layout — so some units are well-understood while the spikes (ticket 03) are inherently
uncertain. The output is the sizing layer of the plan, distinguishing known-effort units from
spike-gated ones.
